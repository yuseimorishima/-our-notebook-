# Renderで公開する

この手順では**有料のWebサービスと永続ディスク**を作成します。Renderに表示される最新の金額を確認してから確定してください。設定ファイルをGitHubに保存するだけでは課金も公開も始まりません。

## 公開

1. [Renderのデプロイ画面](https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2Fyuseimorishima%2F-our-notebook-)を開き、Renderにログインします。
2. GitHubの接続を求められたら、このリポジトリへのアクセスを許可します。非公開リポジトリの場合は必須です。
3. `render.yaml` のWebサービスと永続ディスク、料金を確認してデプロイを実行します。
4. ビルドと起動が成功し `Live` になったら、サービス画面に表示される `https://…onrender.com` を開きます。この実際に発行されたURLがサイトの公開リンクです。
5. 「新規登録」でアカウントを作り、個人ノートを保存して再ログイン後も読めることを確認します。別アカウントでは個人ノートが表示されず、共有ノートは表示・編集できることも確認します。

初回デプロイのDBは空です。開発環境のアカウントやノートは自動転送しません。

## 設定の意味

- SQLiteは永続ディスクの `/var/data/notebook.sqlite` に保存します。無料サービスの一時ファイル領域ではデプロイや再起動時にデータが失われるため、この構成では使いません。
- `APP_ORIGIN` はRenderの `RENDER_EXTERNAL_URL` から起動時に設定します。HTTPS限定のセッションCookieを使います。
- Webサービスは1インスタンスで動かします。複数インスタンスではSQLiteファイルを共有できません。
- ヘルスチェックは `/api/auth/me` を使い、アプリとDBの読み取りが成功することを確認します。
- 独自ドメインに変更する場合は、Renderの `startCommand` を `APP_ORIGIN="https://自分のドメイン" npm start` に変更してください。
- バックアップと復元の運用は別途必要です。稼働中のSQLiteはバックアップAPIでバックアップしてください。ディスクやWebサービスを削除するとデータが失われる可能性があります。

## 公開後の範囲

登録は誰でも行えます。共有ノートは登録ユーザー全員が閲覧・編集できます。個人ノートの内容を共有に切り替えると全登録ユーザーに公開されます。パスワード再設定・招待制登録・変更履歴復元は未実装です。

Renderアカウントの接続・料金確認は所有者が行ってください。パスワード、APIトークン、決済情報をチャットやGitHubに書く必要はありません。
